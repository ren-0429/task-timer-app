# Task Timer App

タスクごとの作業時間を計測するタイマーアプリケーションです。

## 機能

- ⏱️ **複数タスク対応** - 段取り、組立、検査など複数のタスクを管理
- 🔊 **アラーム通知** - 時間終了時に音声アラーム
- 📊 **ログ保存** - 作業時間と遅れを CSV でダウンロード
- 🎨 **シンプル UI** - 使いやすいインターフェース

## セットアップ

### 必要環境

- Node.js 16+
- npm または yarn

### インストール

```bash
npm install
```

### 開発サーバー起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173` を開きます。

### ビルド

```bash
npm run build
```

本番用ファイルは `dist` ディレクトリに生成されます。

## 使い方

1. **タスク選択** - プルダウンからタスクを選択
2. **開始** - 「開始」ボタンをクリックしてカウントダウン開始
3. **停止** - 「停止」ボタンで一時停止
4. **次へ** - 「次へ」ボタンでログ保存と次タスクへ移動

## カスタマイズ

`src/App.jsx` の `tasks` 配列を編集してタスクを追加・変更できます：

```javascript
const [tasks, setTasks] = useState([
  { name: "タスク名", time: 秒数 },
  { name: "組立", time: 600 },
]);
```

## 技術スタック

- **React 18** - UI フレームワーク

- **Tailwind CSS** - スタイリング
